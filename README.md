# Dự án Web Development

> Dự án học tập được xây dựng bằng HTML, CSS và JavaScript thuần bởi nhóm sinh viên Đại học Lạc Hồng.

## Giới thiệu dự án

Dự án là nền tảng để nhóm thực hành quy trình phát triển một website từ giao diện đến tương tác phía trình duyệt. Nhóm sử dụng các công nghệ web cơ bản, không phụ thuộc vào framework, nhằm củng cố kiến thức về cấu trúc trang, trình bày giao diện và xử lý hành vi người dùng.

## Công nghệ sử dụng

- **HTML5** — xây dựng cấu trúc và nội dung trang web.
- **CSS3** — thiết kế giao diện và bố cục.
- **JavaScript (ES6+)** — xử lý tương tác phía trình duyệt.

## Cấu trúc thư mục

```text
project/
├── index.html
├── pages/                  # Các trang bổ sung (nếu có)
│   └── ...
├── assets/
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   └── main.js
│   ├── images/
│   └── icons/
└── README.md
```

**Quy ước:**

- `index.html` là trang chính và là điểm bắt đầu của website.
- `pages/` chứa các trang HTML bổ sung; có thể bỏ qua nếu dự án chỉ có một trang.
- `assets/` chứa tài nguyên tĩnh, được phân loại theo loại tệp để dễ quản lý.
- `README.md` giới thiệu dự án và hướng dẫn sử dụng.

## Cài đặt và chạy dự án

Dự án không cần cài đặt thư viện hoặc công cụ build.

1. Tải hoặc sao chép mã nguồn về máy.
2. Mở thư mục dự án.
3. Mở `index.html` trực tiếp bằng trình duyệt.

Để tự động tải lại trang khi có thay đổi, có thể mở thư mục dự án bằng Visual Studio Code và chạy `index.html` với tiện ích **Live Server**.
